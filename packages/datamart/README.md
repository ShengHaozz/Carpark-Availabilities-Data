# Datamart Package (`packages/datamart`)

The **Datamart Package** extracts pre-computed weekly probability distributions and occupancy metrics from the Gold Layer (`mart_carpark_day_of_week_distribution`), serializes them into lightweight JSON documents via Python standard library dataclasses, and publishes them to S3 for edge caching through **Amazon CloudFront CDN**.

---

## 1. Architecture & Execution Flow

```mermaid
flowchart LR
    SFN["AWS Step Functions\n(carpark-daily-pipeline)"] -->|Task 3: PublishDatamart| Lambda["datamart_publisher Lambda\n(packages/datamart)"]
    Lambda -->|Read Mart CSV| S3CSV["S3: level=mart/target=publisher/"]
    S3CSV -->|Stream & Type Cast| Exporter["Datamart Exporter\n(Pure stdlib dataclasses)"]
    Exporter -->|Upload JSONs| S3Mart[("S3: level=mart/target=downstream/version=v1/\n• carparks/{id}_{lot_type}.json\n• summary/weekly_carpark_distributions.json.gz\n• manifest.json")]
    S3Mart -.->|Private SigV4 (OAC)| CloudFront["Amazon CloudFront CDN"]
    CloudFront -->|Sub-20ms Cached HTTPS GET| Client["Vercel Frontend / Web Clients"]
```

## 2. Package Structure

```text
packages/datamart/src/datamart/
├── __init__.py      # Package export symbols
├── schema.py        # Python dataclass models defining the JSON contract
├── exporter.py      # Tabular mart rows to hierarchical JSON documents serializer
├── publisher.py     # Direct S3 CSV reader and multi-threaded S3 JSON uploader
└── handler.py       # AWS Lambda entrypoint for Step Functions invocation
```

## 3. S3 Key Hierarchy & Endpoints

Base S3 Path: `s3://<BUCKET_NAME>/level=mart/target=downstream/version=v1/`

CloudFront maps `/` directly to `/level=mart/target=downstream/version=v1/`:

| Artifact | S3 Path | CDN Endpoint | Purpose |
| :--- | :--- | :--- | :--- |
| **Manifest Index** | `manifest.json` | `https://<cdn>/manifest.json` | Root index listing all carparks, metadata, and generated timestamp |
| **Individual Carpark** | `carparks/{id}_{lot_type}.json` | `https://<cdn>/carparks/ACB_C.json` | Full 7-day $\times$ 24-hour distribution stats for a single carpark lot type |
| **Summary Bundle** | `summary/weekly_carpark_distributions.json.gz` | `https://<cdn>/summary/weekly_carpark_distributions.json.gz` | GZIP-compressed bundle containing all carparks for client bulk preloading |

## 4. Lambda Environment Variables

| Variable | Required | Default | Description |
| :--- | :--- | :--- | :--- |
| `S3_BUCKET` | **Yes** | — | Target S3 bucket name |
| `INPUT_PREFIX` | No | `level=mart/target=publisher/` | S3 prefix containing the CSV data files generated by dbt |
| `OUTPUT_PREFIX` | No | `level=mart/target=downstream` | S3 prefix where downstream JSONs/manifest are uploaded |
| `DATAMART_VERSION` | No | `v1` | API / contract version prefix |
| `ENV` | No | `prod` | Deployment environment (`prod`, `staging`, `dev`) |
